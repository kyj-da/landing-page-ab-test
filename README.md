# 신규 랜딩페이지 A/B 테스트 분석

신규 랜딩페이지가 구매 전환율과 매출 성과에 미치는 영향을 분석하고, 월별·사용자 세그먼트별 효과와 통계적 유의성을 검증한 프로젝트입니다.

## 프로젝트 개요

- 분석 목적: 신규 랜딩페이지의 구매 전환 효과 검증
- 데이터 규모: 294,478명
- 분석 기간: 2023년 8월 30일 ~ 2025년 8월 30일
- 비교 그룹
  - Control: 기존 랜딩페이지
  - Treatment: 신규 랜딩페이지

## 기술 스택

- Google BigQuery
- SQL
- Python
- Pandas, NumPy
- SciPy, Statsmodels
- Matplotlib
- Tableau

## 분석 과정

1. 데이터 구조 및 품질 점검
2. 전처리 및 파생변수 생성
3. 전체 A/B 성과 비교
4. 월별 성과 추이 분석
5. 사용자 행동 및 매출 분석
6. 연령·성별·기기·국가별 세그먼트 분석
7. 통계 검정
8. Tableau 대시보드 제작
9. 비즈니스 효과 추정 및 적용 전략 제안

## 주요 결과

| 지표 | Control | Treatment | 차이 |
| --- | ---: | ---: | ---: |
| 사용자 수 | 146,926명 | 147,552명 | 626명 |
| 구매 전환율 | 11.87% | 17.95% | +6.08%p |
| 상대 개선율 | - | - | +51.18% |
| 사용자당 매출 | 4.45 | 6.76 | +2.31 |
| 구매자당 평균 구매금액 | 37.50 | 37.68 | +0.18 |

- Treatment의 구매 전환율이 Control보다 6.08%p 높게 나타났습니다.
- 분석 기간의 모든 월에서 Treatment가 Control보다 높은 전환율을 기록했습니다.
- 연령대, 성별, 기기 유형, 국가 등 모든 주요 세그먼트에서 Treatment 우위가 확인됐습니다.
- 세션 지속시간, 방문 페이지 수, 구매자당 평균 구매금액에서는 유의한 차이가 나타나지 않았습니다.
- 약 8,966건의 추가 전환과 337,833.91의 추가 매출 효과를 추정했습니다.

## 통계 검정

구매 전환율 차이에 대해 Two-Proportion Z-test를 수행해 통계적 유의성을 검증했습니다.

사용자 행동과 구매금액은 Welch t-test, Mann-Whitney U test, Cohen's d를 활용해 비교했습니다.

| 지표 | Welch t-test p-value | Mann-Whitney p-value | Cohen's d |
| --- | ---: | ---: | ---: |
| 세션 지속시간 | 0.6720 | 0.4696 | -0.0016 |
| 방문 페이지 수 | 0.2446 | 0.1591 | 0.0043 |
| 구매자 구매금액 | 0.3622 | 0.2430 | 0.0089 |

## 최종 제안

신규 랜딩페이지는 전환율과 사용자당 매출을 개선했고, 성과가 악화된 주요 세그먼트도 확인되지 않았습니다.

따라서 트래픽을 단계적으로 확대하면서 전환율, 사용자당 매출, 이탈률, 오류율을 모니터링한 뒤 전체 적용하는 전략을 제안했습니다.

## 분석 한계

- 공개 데이터셋으로 실제 실험의 랜덤 배정 방식과 운영 조건을 확인할 수 없습니다.
- 기존 페이지와 신규 페이지의 구체적인 디자인 차이가 제공되지 않았습니다.
- 구매금액의 통화 단위가 명시되지 않았습니다.
- 추가 매출 추정에는 개발비, 운영비, 상품 원가 및 마진이 반영되지 않았습니다.
- 장기 재구매율과 고객 생애가치에 미치는 영향은 확인하지 못했습니다.
- 2023년 8월은 일부 기간만 포함된 부분 월입니다.
- 60대 이상 세그먼트는 표본 수가 작아 제한적으로 해석해야 합니다.
